01 / CHECK THE BOARD

Match the hardware

Compare your board to this layout diagram. It is not a photograph or proof of revision compatibility; the same listing can contain other boards. Do not flash if markings or wiring differ.

02 / ENTER USB BOOTLOADER

Connect in ISP mode

Unplug USB. Bridge the empty R12 pads, connect USB-C, then release the bridge. Do not short MCU pins directly or bridge pads while powered.

Expected bootloader USB ID: 4348:55E0. Disconnect other WCH bootloader devices. Windows needs a compatible WCH or WinUSB driver. The button below only watches Windows device status; it never installs or changes a driver.

03 / READ-ONLY PROBE

Check the connected chip

The installer reads the identity and verifies CH552 (0x5211), bootloader 02.50, and the exact local firmware image. It does not write anything yet.

Verified ISP tool needed

On request, this installer downloads the tested GPL-2.0 wchisp release from GitHub. Both archive and executable SHA-256 are checked before it can run. No download happens automatically.

04 / ERASE · FLASH · VERIFY

Review the firmware

This erases and programs code flash, then performs a read-back verify. It leaves the device in bootloader mode; after success, unplug and reconnect without bridging R12.

If a step fails

Stop and keep the full log. Do not repeatedly erase or try another firmware image. R12 remains the documented recovery path, but it cannot restore the absent factory program.
